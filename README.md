# BluFox VPN

کلاینت مستقل اندروید با رابط فارسی و موتور VPN واقعی sing-box / libbox.

## نسخه 0.2.0
- موتور sing-box 1.14.4 از Android libbox
- تونل واقعی Android VpnService با مسیر پیش‌فرض IPv4 و IPv6
- ورود لینک VLESS
- VLESS با TLS یا REALITY و انتقال TCP، WebSocket یا gRPC
- آزمون HTTPS از داخل تونل و نمایش IP خروجی؛ وضعیت متصل فقط بعد از موفقیت آزمون ثبت می‌شود
- اعلان foreground و امکان قطع اتصال از اعلان

## محدودیت‌ها
- فعلاً فقط لینک VLESS پشتیبانی می‌شود؛ VMess، Trojan، Shadowsocks، Hysteria2، WireGuard و OpenVPN هنوز اضافه نشده‌اند.
- فهرست خودکار سرورهای عمومی و پینگ زنده هنوز پیاده‌سازی نشده است.
- این برنامه سرور VPN ارائه نمی‌کند؛ برای اتصال به لینک VLESS معتبر و فعال نیاز داری.
- APK آزمایشی فعلی فقط برای معماری ARM64 ساخته می‌شود؛ روی گوشی‌های ARM64 جدید قابل نصب است.
- لینک واردشده فعلاً فقط در حافظه برنامه نگهداری می‌شود؛ پس از بستن کامل برنامه باید دوباره وارد شود.

## ساخت
از GitHub Actions گردش کار **Build BluFox Android APK** را اجرا کن و APK را از Artifacts دریافت کن.

## مجوز
موتور sing-box و کتابخانه Android libbox تحت GPL-3.0-or-later هستند. سورس متناظر و اطلاعیه‌های مجوز باید همراه نسخه توزیعی ارائه شوند.

## امنیت
سرورهای عمومی ممکن است توسط اشخاص ثالث اداره شوند و قابل اعتماد نباشند. برای اطلاعات حساس از سرور ناشناس استفاده نکن.
